# سالنامه — نسخه مستقل (PWA)

اپ تقویم سالانه شمسی/میلادی با فهرست کارها و یادداشت جلسه (تایپ و Apple Pencil).
بدون نیاز به Claude یا هیچ سرویس دیگری کار می‌کند. داده‌ها فقط روی خود iPad (IndexedDB) ذخیره می‌شوند.

## فایل‌ها
- index.html — خود اپ
- manifest.webmanifest — نام، آیکون و حالت تمام‌صفحه
- sw.js — کار آفلاین
- icon-180.png, icon-192.png, icon-512.png — آیکون‌ها

## نصب روی iPad (یک بار)
اپ باید از یک آدرس https باز شود؛ فایل محلی در Safari آیکون و حالت آفلاین نمی‌گیرد. ساده‌ترین راه رایگان GitHub Pages است:

1. در github.com یک حساب بسازید (یا وارد شوید) و یک repository عمومی جدید با نام salnameh بسازید.
2. Add file → Upload files: هر هفت فایل این پوشه را (بدون پوشه) آپلود کنید و Commit بزنید.
3. Settings → Pages → Branch: main → Save. بعد از یکی دو دقیقه آدرسی مثل
   https://USERNAME.github.io/salnameh/ ساخته می‌شود.
4. این آدرس را در Safari روی iPad باز کنید → Share → Add to Home Screen.
5. از این به بعد آن را از آیکون «سالنامه» روی صفحه اصلی باز کنید (نه از Safari)؛ تمام‌صفحه و آفلاین کار می‌کند.

جایگزین‌های GitHub: Netlify Drop (app.netlify.com/drop — پوشه را بکشید و رها کنید) یا Cloudflare Pages.

## نکات مهم
- داده‌های اپ نصب‌شده از Safari جداست. اگر قبلاً در Safari داده وارد کرده‌اید، از منوی ⋯ پشتیبان بگیرید و در اپ بازگردانی کنید.
- پشتیبان‌گیری: منوی ⋯ → «گرفتن نسخه پشتیبان» → Save to Files (مثلاً در iCloud Drive). اپ هر دو هفته یادآوری می‌کند.
- حذف آیکون از صفحه اصلی، داده‌ها را هم پاک می‌کند؛ قبلش حتماً پشتیبان بگیرید.
- به‌روزرسانی: index.html جدید را جایگزین کنید و در sw.js مقدار VERSION را یک واحد بالا ببرید.
- Apple Pencil با فشار کار می‌کند؛ انگشت به‌طور پیش‌فرض فقط صفحه را اسکرول می‌کند (گزینه «نوشتن با انگشت» برای تغییر آن).
